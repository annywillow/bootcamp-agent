1. PROGRAMME AND AUDIENCE

The programme is the MMAUG 30-Day AI and DevOps Fundamentals Bootcamp.
MMAUG stands for Malta Microsoft AI User Group, an independent community group.
The advertised programme dates are 1–30 October 2026. It connects AI, Python,
Azure, GitHub and practical DevOps learning. The expected daily commitment is
60–120 minutes.

It is intended for beginners, students, career switchers and early-career
technologists. Previous coding experience is helpful but not required.

2. WEEKLY LEARNING PATH

Week 1 — Developer readiness: computer basics, terminal, Git, GitHub and Markdown.
Week 2 — Python and AI: Python foundations, data, AI concepts and responsible AI.
Week 3 — Cloud and DevOps: Azure, testing, DevOps, DevSecOps, AIOps and GitHub Actions.
Week 4 — Build and showcase: prompting, AI-assisted delivery and a portfolio capstone.

The intended outcomes include confidence with the command line, Git, GitHub
and technical documentation; beginner Python scripting; understanding the role
of data in AI; and presenting a documented capstone combining AI and delivery
practices.
